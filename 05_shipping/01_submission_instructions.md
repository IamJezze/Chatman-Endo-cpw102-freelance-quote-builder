# Submission Instructions

Before submitting your assignment, make sure your latest work is pushed to GitHub.

## 1. Commit and Push Your Work

In GitHub Desktop:

1. Make sure **Current branch** shows `development`.
2. Review your changed files. Include your product requirements, engineering design and pseudocode, Python implementation, and completed manual test cases.
3. Enter a short commit summary describing the work you completed.
4. Click **Commit to development**.
5. Click **Push origin**. If the branch has not been published yet, click **Publish branch**.

Make sure your completed files appear on the `development` branch in GitHub.

## 2. Create a Pull Request

Open a pull request from `development` into `main` in your own repository.

1. Open your repository on GitHub.
2. Open the **Pull requests** tab and click **New pull request**.
3. Set the base branch to `main` and the compare branch to `development`.
4. Review the changes and click **Create pull request**.
5. Give the pull request a title identifying Freelance Quote Builder.
6. In the description, briefly explain:
   - What you completed
   - Any known issues or incomplete work
7. Submit the pull request and leave it open for review.

## 3. Submit the Pull Request in Canvas

Copy the URL of your pull request.

Open the assignment submission page in Canvas and submit the pull request URL as your assignment submission.

Do not submit a link to the repository homepage. Submit the link to the pull request.
